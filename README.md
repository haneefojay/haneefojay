# Haneef Ojutalayo

Senior software engineer in Ibadan, Nigeria (UTC+1). I build full-stack products end to end, from backend architecture and data models to web and mobile clients, with a focus on systems that stay correct when networks drop, requests retry and jobs run concurrently.

Currently building the NidCircle mobile app and admin dashboard, and leading client engineering at MushakTech Ventures. Open to remote software engineering roles.

## Selected work

- **[Quotacore](https://github.com/haneefojay/Quotacore)**: self-hosted Go service that enforces usage-based quotas for SaaS products, with atomic check-and-deduct and charge-once retries. Go, PostgreSQL, Valkey, Lua.
- **[Nexus](https://github.com/haneefojay/Nexus)**: multi-tenant field inspection platform with an offline-first PWA and exactly-once sync. Next.js, TypeScript, PostgreSQL, PostGIS.
- **[Paperless PDF Editor](https://github.com/haneefojay/PDF-Editor)**: local-first PDF editor for web and Android where files never leave the device. React, TypeScript, MuPDF WebAssembly, Capacitor.
- **[EnvDoctor](https://github.com/haneefojay/envdoctor)**: open-source Go CLI that validates environment variables against a contract without exposing secrets.
- **[Wallet Service API](https://github.com/haneefojay/Wallet-Service-API)**: wallet backend with Paystack deposits, verified webhooks, atomic transfers and permission-scoped API keys. FastAPI, PostgreSQL.
